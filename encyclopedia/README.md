# Энциклопедия: гормоны, ритмы и природные средства

PDF-справочник (≈70 страниц, A4) по эндокринологии, циркадной биологии и сну, фитотерапии,
лечебным грибам и спорам — с позиций доказательной медицины, с векторными иллюстрациями.

- Готовый файл: `Энциклопедия_эндокринология_циркадные_ритмы_фитотерапия_микотерапия.pdf`
- Исходники: `src/parts/*.html` (главы), `src/style.css` (дизайн), `src/fonts/` (Manrope, Unbounded, Source Serif 4 — SIL OFL).

## Сборка

```bash
pip install pypdf
python3 src/build.py   # HTML → PDF через headless Chromium, двухпроходное оглавление + закладки
```

Путь к Chromium задаётся константой `CHROME` в `src/build.py`.

> Материал образовательный и не заменяет консультацию врача.
