# TVGram — клиент Telegram для Android TV

Полноценное нативное приложение Telegram для телевизоров и ТВ-приставок на Android TV /
Google TV. Kotlin, Jetpack Compose for TV, TDLib.

> **English**: TVGram is a native, unofficial Telegram client for Android TV, written in
> Kotlin with Jetpack Compose for TV on top of TDLib. Documentation is in Russian;
> the source code and its comments are in English.

---

## Краткий вывод

Приложение реализует полный пользовательский сценарий мессенджера в десятифутовом
интерфейсе: вход по QR-коду или номеру телефона (включая двухфакторную защиту), список
чатов с поиском и подгрузкой, переписка с историей и отправкой сообщений, просмотр фото,
воспроизведение видео и аудио, настройки и выход из аккаунта. Управление рассчитано на
пульт: D-pad, крупные шрифты, явная индикация фокуса, экранная цифровая клавиатура вместо
экранной QWERTY там, где вводятся только цифры.

Собрать проект «из коробки» нельзя по объективной причине: **TDLib не публикуется в Maven
для Android**, её нужно один раз собрать самостоятельно
(см. [docs/BUILDING_TDLIB.md](docs/BUILDING_TDLIB.md)) и получить собственные `api_id` /
`api_hash` на [my.telegram.org/apps](https://my.telegram.org/apps).

## 1. Возможности

### Реализовано

| Область | Что работает |
| --- | --- |
| Вход | QR-код (`RequestQrCodeAuthentication`), номер телефона, SMS/Telegram-код, пароль двухфакторной аутентификации, повторная отправка кода |
| Список чатов | Постраничная загрузка главного списка, порядок и закрепление из TDLib, аватары, превью последнего сообщения, счётчик непрочитанного, отметка «без звука», серверный поиск по чатам с debounce |
| Переписка | История с подгрузкой вверх, разделители дат, имена отправителей в группах, отправка текста с оптимистичным отображением, статусы «отправляется» / «ошибка», отметка о прочтении |
| Типы сообщений | Текст, фото, видео, видеосообщения, GIF, аудио, голосовые, документы, стикеры (эмодзи), геолокация, места, контакты, звонки, служебные события; всё остальное — понятная заглушка |
| Медиа | Полноэкранный просмотр фото, воспроизведение видео/аудио в ExoPlayer с D-pad-управлением, полоса прогресса загрузки |
| Настройки | Профиль, увеличенный шрифт, отправка отметок о прочтении, размер и очистка кэша, выход с подтверждением |
| TV UX | Единый примитив фокуса, десятифутовая типографика, тёмная тема, баннер для Android TV Home, `LEANBACK_LAUNCHER` |

### Сознательно не реализовано

Секретные чаты, звонки, отправка медиа, редактирование и удаление сообщений, папки чатов,
анимированные стикеры `.tgs`, опросы, push-уведомления. Неподдерживаемый контент
отображается заглушкой с подсказкой открыть сообщение на телефоне.

## 3. Быстрый старт

```bash
# 1. Собрать TDLib и положить артефакты в app/libs
#    подробности: docs/BUILDING_TDLIB.md
#    результат: app/libs/java/org/drinkless/tdlib/*.java
#               app/libs/jniLibs/<abi>/libtdjni.so

# 2. Прописать свои учётные данные Telegram
cat >> local.properties <<'PROPS'
TELEGRAM_API_ID=1234567
TELEGRAM_API_HASH=0123456789abcdef0123456789abcdef
PROPS

# 3. Проверить, что TDLib на месте
./gradlew :app:verifyTdlib

# 4. Собрать и установить
./gradlew :app:installDebug
```

`api_id` / `api_hash` берутся, в порядке приоритета, из переменных окружения
`TELEGRAM_API_ID` / `TELEGRAM_API_HASH`, затем из `local.properties`, затем из
`gradle.properties`. `local.properties` в `.gitignore` — так и должно быть: условия
использования Telegram запрещают распространять приложение с чужим `api_id`.

### Запуск на устройстве

```bash
adb connect <ip-телевизора>:5555
./gradlew :app:installDebug
adb shell am start -n com.tvgram.debug/com.tvgram.MainActivity
```

### Запуск на эмуляторе

Нужен образ **Android TV**, а не телефона, — иначе `LEANBACK_LAUNCHER` не покажет иконку,
и понадобится ABI `x86_64` в сборке TDLib.

```bash
sdkmanager "system-images;android-34;android-tv;x86_64"
avdmanager create avd -n tv34 -k "system-images;android-34;android-tv;x86_64" -d tv_1080p
```

## 5. Тесты

```bash
./gradlew :app:testDebugUnitTest
```

Юнит-тестами покрыта чистая логика, не зависящая от Android и TDLib: форматирование
длительностей, размеров файлов, счётчиков непрочитанного, инициалов и текстов превью
сообщений. Всё, что требует TDLib, тестируется только на устройстве — подменять её
интерфейс мок-объектами бессмысленно: `TdApi` генерируется и меняется от версии к версии.

## 6. Ограничения и риски

| Ограничение | Причина | Обходной путь |
| --- | --- | --- |
| Видео открывается только после полной загрузки | нужен собственный `DataSource` поверх растущего файла TDLib | ждать загрузку; для длинных видео это заметно |
| Анимированные стикеры не проигрываются | `.tgs` — это gzip-сжатый Lottie, требуется отдельный рендерер | показывается эмодзи стикера |
| Ввод текста зависит от системного IME телевизора | на разных прошивках IME ведёт себя по-разному | для номера и кода используется собственная цифровая клавиатура |
| Приложение неофициальное | использует TDLib и ваш собственный `api_id` | соблюдайте [условия Telegram API](https://core.telegram.org/api/terms) |
| Отсутствие push-уведомлений | требуется FCM и серверная часть | сообщения приходят, пока приложение открыто |
