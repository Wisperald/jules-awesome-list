# Никколо Макиавелли — Энциклопедия (PDF)

**Файл:** [`Machiavelli_Encyclopedia.pdf`](Machiavelli_Encyclopedia.pdf) — ~93 страницы A4, русский язык.

16 разделов: биография и хронология, каталог всех сочинений, архитектура мысли,
словарь из 70 понятий, все 26 глав «Государя», ключевые главы «Рассуждений»,
общие правила «О военном искусстве», «История Флоренции» и «Жизнь Каструччо»,
литература и письма, свод из 150 правил, цитатник (150+ цитат с источниками),
мифы и ложные атрибуции, история интерпретаций, психология макиавеллизма,
применение в управлении, персоналии и библиография.

Цитаты даны в переводе-пересказе по итальянским оригиналам с указанием главы;
правила — редакционные выжимки со ссылкой на источник.

## Сборка

```bash
cd machiavelli
NODE_PATH=$(npm root -g) node build.js   # нужен playwright + Chromium
```

Исходники: `src/parts/*.html` (содержание), `src/style.css` (дизайн), `fonts/` (Playfair Display, Inter, JetBrains Mono — OFL).
