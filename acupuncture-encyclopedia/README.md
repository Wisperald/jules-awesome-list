# Энциклопедия современной китайской акупунктуры (PDF)

Готовый файл: [`Энциклопедия_китайской_акупунктуры.pdf`](./Энциклопедия_китайской_акупунктуры.pdf) — A4, ~71 страница.

Содержание:
- 14 каналов и 361 классическая точка: коды и локализации по WHO Standard Acupuncture Point Locations (2008), традиционные показания, категории точек;
- условный латинский код для мужского и женского тела у каждой точки (`M-ST36` / `F-ST36`), плашки ♂/♀ с документированными половыми различиями;
- точки, совпадающие с миофасциальными триггерами, **подчёркнуты двойной линией**;
- схематические топографические карты каждого канала и обзорные карты тела;
- эндокринология и циркадные ритмы с разделением ♂/♀; традиционные «часы органов» даны отдельным блоком;
- доказательная база, безопасность, источники.

Схемы упрощены и не заменяют анатомический атлас. Издание справочное и не является руководством к самолечению.

## Сборка

```bash
python3 src/build.py                                          # -> build/encyclopedia.html
PW_PATH=/opt/node22/lib/node_modules/playwright node src/render.js   # -> PDF (Chromium/Playwright)
```

Данные точек — `src/points.py`, схемы — `src/figures.py`, текст разделов — `src/content.html`, стиль — `src/style.css`.
