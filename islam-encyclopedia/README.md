# Ислам — Большая энциклопедия (PDF)

История ислама от VII века до 2026 года: ключевые личности, династии, направления, ветви, секты, школы права и вероучения, суфийские ордены, современные движения — с датами, географией и краткими пояснениями.

**Готовый файл:** [`Islam-Encyclopedia.pdf`](Islam-Encyclopedia.pdf) (A4, ≈100 страниц, кликабельное оглавление и закладки).

## Структура
- Часть I. Истоки — Аравия, Пророк, Коран и Сунна
- Часть II. Эпоха халифатов — праведные халифы, Омейяды, Аббасиды, Фатимиды, Андалус, региональные династии
- Часть III. Анатомия разделений — древо течений, хариджиты/ибадиты, все ветви шиизма, друзы, алавиты, алевиты, мазхабы, калам, философия, суфизм
- Часть IV. Империи и распространение — монголы, мамлюки, Тимуриды, османы, Сефевиды, Моголы, Африка, Азия, Казахстан, Кавказ, Россия, Европа
- Часть V. Новое время — реформизм, новые движения, колониализм, политический ислам, джихадизм, мир 2020-х
- Приложения — хронология, сравнительные таблицы, глоссарий, литература

## Сборка
Исходники — HTML-главы в `src/chapters/`, стили — `src/style.css`, шрифты (OFL) — `fonts/`. Вёрстка: Paged.js + Chromium (Playwright).

```bash
NODE_PATH=$(npm root -g) node build.js   # -> Islam-Encyclopedia.pdf
```
